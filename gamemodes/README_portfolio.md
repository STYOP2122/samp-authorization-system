# SA-MP Account System — настройка

Небольшой мод для SA-MP с регистрацией и входом по аккаунту. Данные хранятся в MySQL (плагин a_mysql).

## Возможности

- **Регистрация** — при первом заходе по нику предлагается ввести пароль (4–32 символа).
- **Вход** — при повторном заходе запрашивается пароль.
- Пароли хранятся в виде хеша **SHA256** с уникальной солью на аккаунт.
- Команды: `/stats` (аккаунт и ID в БД), `/q` или `/quit` (выход с сервера).

## Требования

- SA-MP сервер 0.3.DL (или совместимый)
- Плагин **mysql** (a_mysql R41+)
- Сервер MySQL / MariaDB

## Установка

1. **База данных**  
   Создай БД и таблицу (один раз):
   ```bash
   mysql -u root -p < sql/schema.sql
   ```
   Либо выполни содержимое `sql/schema.sql` вручную в phpMyAdmin/HeidiSQL и т.п.

2. **Настройка подключения**  
   В начале файла `gamemodes/portfolio_rp.pwn` задай параметры MySQL:
   ```pawn
   #define MYSQL_HOST      "127.0.0.1"
   #define MYSQL_USER      "root"
   #define MYSQL_PASS      "твой_пароль"
   #define MYSQL_DB        "portfolio_samp"
   ```

3. **Сборка**  
   Скомпилируй геймод в Pawno: открой `portfolio_rp.pwn`, нажми F5. Убедись, что в списке инклудов есть путь к `a_mysql.inc` (например, `pawno/include/`).

4. **Запуск сервера**  
   В `server.cfg` укажи геймод и плагин mysql:
   ```ini
   gamemode0 portfolio_rp 0
   plugins mysql
   ```
   Положи `portfolio_rp.amx` в папку `gamemodes/`, плагин `mysql` — в `plugins/`.

## Структура БД

Таблица `accounts`:

| Поле        | Описание                          |
|------------|------------------------------------|
| id         | AUTO_INCREMENT                     |
| name       | Никнейм (уникальный)               |
| pass       | SHA2(пароль + salt)                |
| salt       | Случайная строка для соли          |
| created_at | Дата регистрации                   |
| last_login | Последний вход                     |

## Команды

| Команда   | Описание                    |
|-----------|-----------------------------|
| /stats    | Показать ник и ID аккаунта  |
| /q, /quit | Выход с сервера             |

## Реализация

- Подключение к MySQL через **a_mysql**, асинхронные запросы `mysql_pquery`.
- Пароли хранятся в виде SHA256-хеша с солью.
- Диалоги ввода пароля (`DIALOG_STYLE_PASSWORD`), проверка длины пароля.
- Простая расширяемая схема (можно добавить поля в `accounts` или новые таблицы).
